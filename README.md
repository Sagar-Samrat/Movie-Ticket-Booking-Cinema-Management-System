# 🎬 CineBook — Movie Ticket Booking & Cinema Management System

CineBook is a frontend-based Movie Ticket Booking and Cinema Management System developed using **HTML5 and CSS3**.

The project provides a user-friendly interface for browsing movies, viewing movie details, selecting theatres and showtimes, choosing seats, viewing booking information, and managing cinema-related information through an admin dashboard.

> **Technology Restriction:** This project is developed using only HTML and CSS. No JavaScript, backend, database, or external framework is used.

---

# 📌 Project Objectives

The main objectives of this project are:

- Provide a clean and responsive movie booking interface.
- Display currently available and upcoming movies.
- Allow users to explore movie details.
- Provide a theatre and showtime selection interface.
- Provide a visual cinema seat-selection interface.
- Provide login and signup pages.
- Provide a user profile and booking-history interface.
- Provide an admin dashboard for cinema management.
- Practice collaborative development using Git and GitHub.
- Follow a proper branch-based development workflow.
